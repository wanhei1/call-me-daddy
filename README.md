# Call Me Daddy

A simple interactive website featuring a button that displays a "DADDY!!" notification when pressed.

## Features

- Large, eye-catching button
- Visual notification
- Attempts browser notifications if permitted

## Usage

Simply visit the GitHub Pages site and press the button to see the notification.
